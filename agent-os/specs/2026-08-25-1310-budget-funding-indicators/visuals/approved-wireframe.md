# YNAB category-row scan layer

The attached screenshot (`ynab-category-rows.jpg`, gitignored) is the visual target:

- Progress bar under the category name (yellow underfunded, green funded / on track,
  dashed/striped when fully spent, absent when idle $0).
- Status copy in the name column: `$X more needed this month`, `Funded. Spent $X of $Y`,
  `Fully Spent`, `On Track`, `Funded`.
- Available as a colored pill with an icon (clock / check / pie).

Do not re-scrape YNAB. The screenshot was supplied with the request that opened this spec.
