# Approved Settings workspace wireframe

## Desktop — 1280 × 800

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ ← Back to Planner  /  Settings                                             │
├───────────────────┬─────────────────────────────────────────────────────────┤
│ SETTINGS          │ GENERAL                                                 │
│                   │ Display defaults and everyday Planner behavior.         │
│ ▌ General         │ ─────────────────────────────────────────────────────── │
│   Views & layout  │ DATE FORMAT                                             │
│   Connections     │ [ M/D/YYYY                                      ▾ ]     │
│   Import & export │ Sample     1/5/2026                                     │
│   Account         │ [ Restore Achieve default ]                             │
│                   │                                                         │
│                   │                                                         │
└───────────────────┴─────────────────────────────────────────────────────────┘
```

The active item has a `select-edge` rule on the surface-facing edge. The rail and content
share ruled boundaries; there are no floating cards or new accent colors.

## Compact — 390 × 844

```text
┌──────────────────────────────────────┐
│ ← Back to Planner  /  Settings       │ safe top
├──────────────────────────────────────┤
│ [ General                         ▾ ] │ 44px
├──────────────────────────────────────┤
│ GENERAL                              │
│ Display defaults and everyday        │
│ Planner behavior.                    │
│ ──────────────────────────────────── │
│ DATE FORMAT                          │
│ [ M/D/YYYY                        ▾ ] │ 44px
│ Sample                               │
│ 1/5/2026                             │
│ [ Restore Achieve default          ] │ 44px
│                                      │
└──────────────────────────────────────┘ safe bottom
```

Each category replaces the one work area; there is no horizontal rail or page-level
horizontal scrolling.
