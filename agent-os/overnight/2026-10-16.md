## Needs a decision

- **CSV exports are not neutralised against spreadsheet formulas.** `grid/exportCsv.ts` and
  `finances/audit/export.ts` write cell text verbatim, so a payee, description or product name
  that begins with `=`, `+`, `@` (or `-`) is a live formula when the file is opened in Excel or
  Sheets. The text comes from bank feeds and Amazon exports, i.e. from third parties. The
  standard fix prefixes such a cell with `'`, which also touches a negative amount unless
  numeric columns are exempted — and it changes what a round trip through the app's own CSV
  import reads back. **Recommendation:** neutralise only string cells of text-kind columns, never
  amount or date columns, and have the importer strip a leading `'` it finds on a text field.
  Worth doing, but it changes export bytes, hence not unattended. — blocking: nothing.
