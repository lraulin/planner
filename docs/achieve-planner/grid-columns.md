is based on the supplied field lists (2026-08-04), with obvious transcription spacing
normalised. It records available fields, not default layouts.

[`agent-os/specs/2026-08-04-1530-grid-column-parity/plan.md`](../../agent-os/specs/2026-08-04-1530-grid-column-parity/plan.md).
