**IMPORTANT NOTE for Vista Users**
Windows Vista and Windows 7 come pre-installed with the Microsoft .NET version 3.5, which usually works fine with Achieve Planner.
A small number of Vista users are reporting strange problems with Achieve Planner when running on Vista, like windows not being displayed correctly.
If you experience any problems with Achieve Planner while running on Vista, you may want to manually install the 1.1 version of the Microsoft .NET framework for use with Achieve Planner because this usually resolves these strange problems.
You can get the installer directly from Microsoft ([click here](http://www.microsoft.com/downloads/details.aspx?FamilyId=262D25E3-F589-4842-8157-034D1E7CF3A3&displaylang=en "Download .NET Framework Runtime") for the download page). Make sure to run automatic updates to get any service packs and patches.
The different versions of the .NET framework can be installed side-by-side on Vista without any problems.
