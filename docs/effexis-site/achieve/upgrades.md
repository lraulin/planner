# Achieve Planner Upgrade Policy

This page describes the upgrade policy for Achieve Planner customers to upgrade to future releases of the software.
Updates to the latest minor release within the same major release (for example, from 1.5 to 1.8) are included for free as part of your purchase.
Upgrades to a new major release (for example, from 1.x to 2.x) may require you to pay an upgrade license fee with a possible discount depending on when you purchased the previous version.
