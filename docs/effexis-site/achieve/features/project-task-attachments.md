# Project/Task Attachments Feature

The project/task attachments feature available starting with release 1.2, provides a way to link files in the hard drive and arbitrary URLs with projects and tasks.

## Associating Attachments

The project/task information forms now include an Attachments tab, where you can add, delete, and launch attachments associated with the item.
The Actions menu has a quick launch command (Actions->Attachments) to help you quickly add/modify/delete attachments associated with a particular project/task.

## Browsing for Files

For file attachments, you can click on the button in the URL cell of the attachments grid, or on the _Browse..._ button to bring up a file selection dialog.

## Launching Attachments

You can launch the associated attachment by double-clicking on the attachment row, or by clicking the _Launch..._ button.
