# Capture & Organize New Projects/Tasks

## 5\. Capturing New Projects & Tasks

I mentioned before that writing things down to get them out of your head and into your productivity system is a very good time management practice.
Achieve Planner makes this very quick and easy. You can always enter projects and tasks directly into the Outline, but you can also use the 'Quick Task Entry' feature to speed up the process.
You can access the Quick Task Entry from the Achieve Planner notification icon in the Windows taskbar or by using a configurable Hot Key (Alt+Win+T) that you can invoke from any application.
From here, you can create one or more tasks (using indentation to create subtasks).
By default, all new tasks created this way are stored under the 'Inbox' project for later processing, but you can also assign them to a specific project instead.

  6\. Organizing New Projects/Tasks
  When you capture new projects/tasks without specifying a parent project, Achieve Planner stores them in a special **Inbox** project for later processing.
  When you are ready to process them, you can use the **New Task Organizer Wizard** (available from the Tools menu) to help you decide how to handle them...
  [ ](../screenshots19/NewTaskOrganizerSS.png)
  Click Image to View Larger Size
  The Wizard helps you decide what type of item it is (a project, a task, a non-actionable note/reference item, or something to delete right away.)
  You can then change the name/priority, set the parent, and add other details like context and deadline.
  You can also **defer** the item to a future date for later processing (like a tickler file).
