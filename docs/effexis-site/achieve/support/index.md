Achieve Planner Contact & Support
NOTE: The Achieve Planner Software is no longer available for sale.
If you have a support question/request about the Achieve Planner software, please send an email to esupport at effexis.com to contact us to ensure the best response.
Achieve Planner is a Windows application. There is no Mac or Linux native version. We currently do not have any plans for developing or supporting Mac or Linux versions of Achieve Planner, although many Mac users use a "virtual PC" software like Parallels to run Windows software on the Mac.
