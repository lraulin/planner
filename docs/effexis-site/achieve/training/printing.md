# Printing the Achieve Planner Grids

Achieve Planner supports two main styles of printing.
Printing the Grids
The default style is to print the grids as they are shown on screen
You can do this using the File -> Print and File -> Print Preview menu commands.
Here are some tips for getting the best results when you print the grids.

1. Achieve Planner will try to fit the grid as displayed on the screen into the page. This could result in the font being significantly scaled down to fit.
   If the font display is too small, try reducing the size of the grid display as follows:

- Use the View -> Fit to Window menu item and make sure it's turned off (unchecked)
- Reduce the size of the main title column (typically Name) to make the grid display smaller
- If needed, remove some columns using View -> Customize Current View menu item to make the grid display smaller
- Use File -> Page Setup menu item to switch to landscape view

2. Use Tools -> Options menu item (Grids tab) to set a larger font size when printing - Use this in combination with tip # 1 because Achieve Planner will still try to scale the grid down to make it fit in the page
3. Use the new 'Active Printing' views which contain fewer columns and have the 'Fit to Window' setting turned off.
   You can find these new views in the View dropdown in the various tabs. NOTE: These views are available in the 1.9.1 release.
   Printing the Details
   In some cases, you may want to print additional details that are NOT available from the standard grid display.
   You can use the File -> View Report menu item to print a more detailed report of selected rows in the following tabs.
4. Projects Tab - Select the rows and use File -> View Report to print a detailed report for each selected project
5. Tasks Tab - Select the rows and use File -> View Report to print a listing for each selected task including the task notes
6. Notes Tab - Select the rows and use File -> View Report to print a listing including the note text
7. Weekly Schedule - Use File -> View Report to print a listing of appointments and events including the notes
