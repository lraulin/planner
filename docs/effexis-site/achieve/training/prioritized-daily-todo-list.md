# Creating A Prioritized Daily To-Do List

A prioritized daily to-do list is a list of tasks that you are planning to do on a particular day that you've prioritized using the ABCD system based on their importance and urgency.
Achieve Planner's Task Chooser provides extensive support for creating and using a prioritized daily to-do list that is independent of your Outline/Project structure and it's priorities.
The system relies on the Task Chooser's ability to “pick out” tasks across all projects and to filter/sort them in various ways.
[Review this lesson for more on the Task Chooser and Contexts](structured-vs-unstructured.md).
**Selecting Your Daily 'To-Do’s'**
You'll want to start by selecting the tasks that you want to include in your prioritized daily to-do list from all the tasks that are available in the master outline.
One easy way to do that is to use a [ Context](structured-vs-unstructured.md#Contexts) to tag the tasks that you want to include in your list. For example, you could tag them with a 'Todo' context to indicate that they should be included in your daily to-do list.

**Viewing Your Daily 'To-Do’s' In The Task Chooser**
Once you've tagged the tasks you want to see with the Todo context, you can use the Task Chooser's context filtering to give you a list of tasks that match that context.
Here's what you need to do:

1. Go to the Task Chooser tab (Go -> Task Chooser menu item)
2. Select the 'Todo List' view from the Task Chooser view selector
   I recommend using this view because it's already sorted by the Task Chooser priority column and it's a good choice to represent your prioritized daily to-do list.
3. Show the Task Chooser's advanced filtering options by checking the Advanced Filters checkbox
4. Enter Todo as the Context to filter by...
   That will give you a filtered lists with only the tasks that match the Todo context...
   [ ](images/PrioritizedTodoList/TCTodoListDisplayed.png)
   Click On Image to Enlarge
   You'll notice that the list is filtered and only shows the 3 tasks that I tagged with the Todo context.
   You'll also notice that the priority is blank, even though these tasks had a priority set in the Outline. The reason for this is that this view shows a new priority field (the 'Task Chooser Priority') that is completely independent from the priority of the task in the Outline.
   In this view, the list is sorted by the Task Chooser Priority (see the grid title bar immediately above the column headings), so if you change those task chooser priority values, the list will be sorted accordingly.
   That's how you can create and view a Prioritized Daily To-Do List using Achieve Planner's Task Chooser.
