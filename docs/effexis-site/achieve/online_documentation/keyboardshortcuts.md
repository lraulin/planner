# Achieve Time Management & Goal Setting Software Help - Keyboard Shortcuts

_Archived from [http://www.effexis.com/achieve/online_documentation/keyboardshortcuts.htm](http://www.effexis.com/achieve/online_documentation/keyboardshortcuts.htm)_

---

Keyboard shortcuts simplify the completion of common tasks. Achieve supports fully customizable keyboard shortcuts for all application commands. Shortcuts available for commands are displayed next to the menu entry for each command and in the status bar description of the command.
Achieve supports two types of shortcuts:
· Simple shortcuts consisting of a single combination of keys
· Chord shortcuts consisting of two consecutive shortcut key combinations
The shortcut _Ctrl+S_ is an example of a simple shortcut used to save changes to the data file.
The shortcut _Ctrl+Shift+P, V_ is an example of a chord shortcut used to display the print preview for the active view.
To use a chord shortcut, press the first set of keys in the chord (_Ctrl+Shift+P_) followed by the second set of keys (_V_). When the first set of keys is pressed, the status bar will change to indicate that the application is waiting for the completing sequence. _Note that in this example, the second key (V) does not require that the Ctrl key be pressed._
Press the second key combination of the chord or _Esc_ to cancel the chord shortcut.
