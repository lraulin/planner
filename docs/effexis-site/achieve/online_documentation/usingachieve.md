# Achieve Time Management & Goal Setting Software Help - Using Achieve

_Archived from [http://www.effexis.com/achieve/online_documentation/usingachieve.htm](http://www.effexis.com/achieve/online_documentation/usingachieve.htm)_

---

The Achieve main workspace window provides access to all the visible views (using tabbed interface), the main application menu and the toolbar.
Grids are used extensively in the Achieve user interface and behave similarly in all views. See [Using Grids](usinggrids.md) topic for more details.
The following top-level views are available (use the [Go menu](gomenu.md) to open or navigate to a top-level view):
· Outline (Achieve Planner Pro)
· [Result Areas](resultareas.md) (Achieve Planner Pro)
· [Wish List](wishlist.md) (Achieve Goal Organizer)
· [Dreams](dreams.md) (Achieve Goal Organizer)
· [Goals](goals.md) (Achieve Goal Organizer)
· [Metrics](metrics.md) (Achieve Goal Organizer)
· [Projects](projects.md) (Achieve Planner)
· [Tasks](tasks.md) (Achieve Planner)
· [Weekly Schedule](weeklyschedule.md) (Achieve Planner)
· [Contacts](contacts.md) (Achieve Planner)
· [Resources](resources.md) (Achieve Planner Pro)
· [File Organizer](fileorganizer.md) (Achieve Planner Pro)
· [Notes](notes.md) (Achieve Planner Pro)
All views are available from the Achieve Productivity Suite edition.
