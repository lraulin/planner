# Achieve Time Management & Goal Setting Software Help - Actions Menu

_Archived from [http://www.effexis.com/achieve/online_documentation/actionsmenu.htm](http://www.effexis.com/achieve/online_documentation/actionsmenu.htm)_

---

The Actions menu provides top-level view specific commands and record/row manipulation commands. The figure below shows the Actions menu for the [Tasks](tasks.md) top-level view
Refer to the top-level view topics for more details on view specific actions ([listed here](usingachieve.md).)
**Reschedule
In Projects/Tasks view, reschedules the projects/tasks based on the latest data (see [Project/Task scheduling](projecttaskscheduling.md))
TIP: you can toggle the expansion state of a single row using the expansion indicator or by pressing _Spacebar_ key while the cell with the expansion indicator is active.
