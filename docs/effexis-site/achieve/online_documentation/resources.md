# Achieve Time Management & Goal Setting Software Help - Resources

_Archived from [http://www.effexis.com/achieve/online_documentation/resources.htm](http://www.effexis.com/achieve/online_documentation/resources.htm)_

---

The Resources view uses a grid to display resources for all projects. See [Using Grids](usinggrids.md) for help with the grid user interface. Resources are sorted in order of increasing resource name.
Resources are used in [project/task scheduling](projecttaskscheduling.md) to represent a person or group that can work on tasks. In general, you should use a short name to represent resources (for example, Joe Smith could be represented by the resource JSmith) and link each resource to a contact to identify the person behind the resource (you can set the contact through the Resource Information form described below.)
You can open the selected resource row(s) to reveal the Resource Information form. To open a row you can: double click on it, press _Ctrl+Enter_ or invoke the **File Open Open Selected Items...** command from the [file menu](filemenu.md) or [standard toolbar](standardtoolbar.md).
**Resource Information Form

****The resource information form allows you to specify the amount of work that can be performed by each resource.
**Resource Name**
Name used for the resource (short resource name format is recommended)
**Contact**
Contact linked to the resource
**Overhead**
Amount of overhead associated with the resource. Overhead represents a certain percent of the resource that cannot be devoted to projects/tasks (for example meetings, interviews, checking email, general management tasks, etc). Typical overhead values range from 10% to 20% but can be higher or lower depending on circumstances. Overhead time is subtracted from resource availability and is not included during scheduling computations
**Effectiveness**
Effectiveness of the resource compared to an average team member. Higher effectiveness values (over 100%) mean the resource can do more work than average in the same amount of time, while lower values mean the resource can do less work than average.
**Monday WH**
Total number of work hours for the resource on Mondays
**Tuesday WH**
Total number of work hours for the resource on Tuesdays
**Wednesday WH**
Total number of work hours for the resource on Wednesdays
**Thursday WH**
Total number of work hours for the resource on Thursdays
**Friday WH**
Total number of work hours for the resource on Fridays
**Saturday WH**
Total number of work hours for the resource on Saturdays
**Sunday WH**
Total number of work hours for the resource on Sundays
**Description**
Description for the resource
The **Edit Calendar...** button allows you to adjust the calendar for the resource to include things like vacations/holidays or part time availability periods. See Resource Calendars for details.
