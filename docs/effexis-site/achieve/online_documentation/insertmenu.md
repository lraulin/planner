# Achieve Time Management & Goal Setting Software Help - Insert Menu

_Archived from [http://www.effexis.com/achieve/online_documentation/insertmenu.htm](http://www.effexis.com/achieve/online_documentation/insertmenu.htm)_

---

The insert menu provides commands for inserting rows into grids. See [Inserting New Rows](usinggrids.md#insertingnewrows) topic for more details.
**Insert at Top-Level**
Insert a new row as a top-level row (with no parent)
**Insert Before**
Insert a new row before the current row and shift priorities of other rows accordingly
**Insert After**
Insert a new row after the current row and shift priorities of other rows accordingly
**Insert as Child**
Insert a new row as a child of the current row
