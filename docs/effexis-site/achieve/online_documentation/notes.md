# Achieve Time Management & Goal Setting Software Help - Notes

_Archived from [http://www.effexis.com/achieve/online_documentation/notes.htm](http://www.effexis.com/achieve/online_documentation/notes.htm)_

---

The Notes view uses a grid to display all note items. See [Using Grids](usinggrids.md) for help with the grid user interface. By default, note items are sorted in order of increasing note title.
You can use the Note view to store/organize all your notes on various subjects.
Each note has the following main fields:
**Title**
Title of the note
**Description**
More detailed description of the note
**Keywords**
Keywords for the note (useful for filtering)
**Type**
User supplied type for the note
**Subject**
User supplied subject for the note
**Date**
Date of the note
Use the view bar to change views, change or remove filtering or change group by columns. The Notes view also supports changing the sorting of the rows by clicking on the column headers.
You can open the selected note row(s) to reveal the Note Information form. To open a row you can: double click on it, press _Ctrl+Enter_ or invoke the **File Open Open Selected Items...** command from the [file menu](filemenu.md) or [standard toolbar](standardtoolbar.md).
The Note Information Form contains the full RTF text for the note.
You can view a detailed report of the Note using the **File View Report...** command.
