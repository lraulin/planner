# Achieve Time Management & Goal Setting Software Help - Time Charts

_Archived from [http://www.effexis.com/achieve/online_documentation/timecharts.htm](http://www.effexis.com/achieve/online_documentation/timecharts.htm)_

---

Learn more about time charts online at _<http://www.timethoughts.com/timemanagement/time-charts.htm>_
Time charts are a tool used during the weekly planning process to help organize your time around the major result areas in your life. A time chart is simply a weekly view of your schedule where you allocate time to "activity zones" rather than specific projects.
These activity zones (or time chart areas) are displayed in the background of the weekly schedule.
You can create multiple time charts to give each week a different focus. Each time chart reflects the way in which you want to spend your time on that particular week.
Use the Time Chart dropdown to select the time chart that you want to display in the background, or None to not display any time chart.
**Creating a Time Chart

****Use the 'New Time Chart...' button in the weekly schedule to create a new time chart using the[Time Chart Information Form](timechartinformationform.md). You can also create new time charts using the Time Charts tab (available from the Go menu.)
**Editing a Time Chart

****Use the[Time Chart Information Form](timechartinformationform.md) to edit the activity zones in the time chart. You can edit existing time charts using the 'Edit Time Chart...' button in the weekly schedule, or by using the Time Charts tab (available from the Go menu.)
**Deleting a Time Chart

****You can delete existing time charts using the Time Charts tab (available from the Go menu.)
