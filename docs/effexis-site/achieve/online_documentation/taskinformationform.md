# Achieve Time Management & Goal Setting Software Help - Task Information Form

_Archived from [http://www.effexis.com/achieve/online_documentation/taskinformationform.htm](http://www.effexis.com/achieve/online_documentation/taskinformationform.htm)_

---

The task information form contains additional details for each task and consists of the following tabs: General, Schedule, Contacts and Details.
**General Tab

****The general tab provides the following fields:
**TaskId**
Unique identifier for the task (typically not needed)
**Name**
Name of the task
**Priority**
Priority of the task
**Project**
Project that owns the task
**State**
Current state of the task
**Schedule Status**
Current schedule status of the task
**Parent**
Parent task (if any)
**Sub Tasks**
Number of immediate child tasks
**Description**
Description of the task
**Categories**
Categories for the task
**Place**
Location/Place context for the task
**Deadline
Optional deadline for the task
**Reminder
Check to set the reminder for the task, uncheck to clear it
**Reminder Date/Time
Date & time for the task reminder
**Schedule Tab

****The schedule tab provides task scheduling details and task resource assignments.
**Total Effort
Total expected effort needed to complete the task (can be computed from Low/Best/High values)
**Effort Left
Amount of effort that is still required to complete the task
**Actual Effort
Actual effort that was needed in order to complete the task
**Effort Driven
Indicates if the task scheduling should be based on effort values. Tasks that are not effort driven are not automatically scheduled.
**Lead Time
Lead time is used to determine the deadline value for new recurring instances of the task (see [Project/Task recurrence](projecttaskrecurrence.md) for details)
**Target Start Date**
Target start date for the task (when it is scheduled to start)
**Target End Date**
Target end date for the task (when it is scheduled to end)
**Actual Start Date**
Date when the task was actually started
**Date Completed**
Date when the task was completed
**% completed**
Percent of the task that has been completed
**Effort Low**
Low estimate for the total effort required to complete the task. Represents the minimum amount of effort it could possibly take to complete the task assuming that everything went according to plan
**Effort Best**
Best guess estimate for the total effort required to complete the task
**Effort High**
High estimate for the total effort required to complete the task. A reasonable upper limit on the maximum effort it could take to complete the task assuming some things go wrong or significant rework is required
**Duration**
Scheduled duration for the task (calendar duration)
**Milestone**
Indicates if the task is a milestone or not
**Cost Low**
Low cost estimate for the task
**Cost High**
High cost estimate for the task
**Actual Cost**
Actual cost for the task so far
**Task Constraint**
Constraint for the task used during scheduling (see [Task Constraints](taskconstraints.md))
**Constraint Date**
Date of the constraint (if any)
**WBS**
WBS code for the task
**Task Resource Assignments**
Explicit resource assignments for the task (see [Task Resource Assignments](taskresourceassignments.md))
**Contacts Tab

****The contacts tab can capture contacts associated with the task.
**Details Tab

****Additional details and notes for the task.
**Attachments Tab**
Allows you to add/delete and launch attachments/URLs associated with the task. Use the "browse" button to associate an existing file with the selected attachment row, and the "launch" button to open the file/URL for the selected row.
