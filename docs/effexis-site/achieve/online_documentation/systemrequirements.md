# Achieve Time Management & Goal Setting Software Help - System Requirements

_Archived from [http://www.effexis.com/achieve/online_documentation/systemrequirements.htm](http://www.effexis.com/achieve/online_documentation/systemrequirements.htm)_

---

Achieve runs on Microsoft Windows compatible computers.
We recommend the following minimum system requirements.
**_Hardware

· Pentium-class CPU, 500 MHz or faster (1 GHz recommended)
· At least 64 MB of memory (256 MB recommended)
· At least 15 MB of free hard-drive space (plus additional 75MB required by Microsoft .NET framework if not already installed)
**_Software

· Microsoft Windows 2000, Windows XP, Windows 2003, Windows NT4.0 with SP6a
· Windows Installer 2.0 (installer will download if necessary)
· The software requires the Microsoft .NET framework V1.1 to be installed. If not already installed in your system, the installer will prompt you to download it from InstallShield's website for installation.
