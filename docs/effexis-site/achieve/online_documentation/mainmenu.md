# Achieve Time Management & Goal Setting Software Help - Main Menu

_Archived from [http://www.effexis.com/achieve/online_documentation/mainmenu.htm](http://www.effexis.com/achieve/online_documentation/mainmenu.htm)_

---

The main menu provides access to the commands of the Achieve application and contains the following top-level popup menus:
**[File](filemenu.md)****
File management, passwords, reports, print
**[Edit](editmenu.md)****
Undo/redo, clipboard commands, delete
**[View](viewmenu.md)**
View navigation & customization
**[Insert](insertmenu.md)**
Insert rows into grids
**[Outline](outlinemenu.md)****
Manipulate items in the grid outline (various tabs supporting outlines)
**[Go](gomenu.md)****
Go to a new top-level view
**[Format](formatmenu.md)**
Format notes
**[Tools](toolsmenu.md)**
Wizards, change working time, keyboard customization & other tools
**[Actions](actionsmenu.md)**
Actions related to the current top-level view and associated grid
**[Window](windowmenu.md)**
Window management & navigation
**[Help](helpmenu.md)**
Help & registration
