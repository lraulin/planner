# Achieve Time Management & Goal Setting Software Help - Edit Menu

_Archived from [http://www.effexis.com/achieve/online_documentation/editmenu.htm](http://www.effexis.com/achieve/online_documentation/editmenu.htm)_

---

The edit menu provides undo/redo, clipboard and delete commands.
**Undo
Undo the last action or command (not all actions can be undone)
**Redo
Redo the last undone action or command
**Cut
Cut the active cell or selected control text
**Copy
Copy the active cell or selected control text
**Paste
Paste the text into the active cell or selected control
**Delete
Delete the selected item(s)
**Find...
Find text within the current view
**Find Next
Find the next occurrence of the previously searched item
The edit menu also contains row pickup/drop commands which can be used to move and copy rows in a grid:
**Pickup row(s)**
Pickup selected rows/records for potential future drop.
**Drop at Same Level**
Drop picked-up records at the same level as target row and reprioritize rows if appropriate
**Drop as Child**
Drop picked-up records as children of the target row.
**Drop Copy as Child**
Drop copies of the picked-up records as children of the target row.
**Drop Copy at Same Level**
Drop copies of the picked-up records at the same level as the target row.
