# Achieve Time Management & Goal Setting Software Help - Tools Menu

_Archived from [http://www.effexis.com/achieve/online_documentation/toolsmenu.htm](http://www.effexis.com/achieve/online_documentation/toolsmenu.htm)_

---

The Tools menu provides [Outlook Synchronization](outlooksynchronization.md), various wizards and customization commands:
**Outlook Synchronization...
See [Outlook Synchronization](outlooksynchronization.md) topic for more details.
**Getting Started Wizard...
Invokes the [Getting Started Wizard](gettingstartedwizard.md)
**Daily Planning Wizard...
Invokes the [Daily Planning Wizard](dailyplanningwizard.md)
**Weekly Planning Wizard...
Invokes the [Weekly Planning Wizard](weeklyplanningwizard.md)
**Wish Brainstorming Wizard...
Invokes the [Wish Brainstorming Wizard](wishbrainstormingwizard.md)
**Project/Task Capture Wizard...**
Invokes the [Project/Task Capture Wizard](projecttaskcapturewizard.md)
**Change Working Time...
Changes the working time associated with the default calendar (e.g., Holidays)
**Project Block Scheduling Options...
Change settings related to the use of project blocks during scheduling
**Customize Keyboard...
Allows you to customize the keyboard interface
**Options...**
Allows you to [configure application options](options.md)
