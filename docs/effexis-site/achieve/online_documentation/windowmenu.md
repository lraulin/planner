# Achieve Time Management & Goal Setting Software Help - Window Menu

_Archived from [http://www.effexis.com/achieve/online_documentation/windowmenu.htm](http://www.effexis.com/achieve/online_documentation/windowmenu.htm)_

---

The Window menu provides commands for creating new Windows for the data file and navigating to existing top-level view windows.
**New Application Window**
Create a new top-level window showing the same data file information
**New Window**
Create a new view window for the current top-level view
**Close All Windows**
Close all top-level view windows
