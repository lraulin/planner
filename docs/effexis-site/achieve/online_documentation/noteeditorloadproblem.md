# Achieve Time Management & Goal Setting Software Help - Note Editor Load Problem

_Archived from [http://www.effexis.com/achieve/online_documentation/noteeditorloadproblem.htm](http://www.effexis.com/achieve/online_documentation/noteeditorloadproblem.htm)_

---

In some rare cases, there may be some problems loading the Note editor with the Rich (RTF) text data stored in the note.
If this is the case, the Notes panel will be disabled to avoid accidental overwrite of data. The contents of the Note (both RTF and normal text) will be stored in the Clipboard so you can try and recover the note text using an alternate program. For example, you could try pasting the text into Notepad or Wordpad.
If you experience this problem, please send the error report to Effexis to help diagnose the problem.
