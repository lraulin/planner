# Achieve Time Management & Goal Setting Software Help - File Menu

_Archived from [http://www.effexis.com/achieve/online_documentation/filemenu.htm](http://www.effexis.com/achieve/online_documentation/filemenu.htm)_

---

The file menu provides file management, report and printing commands.
**New
Create new items or a new Achieve data file
**Open
Open selected item(s) or an existing Achieve data file
**Save
Save the current Achieve data file
**Save As...
Save the current Achieve data file under a different name
**Set Password...
Set or clear the password for the data file (see [Changing Password Protection](changingpasswordprotection.md))
**Export to Excel...
Export current grid view to Excel
**View Report...
View a report for selected records
**Page Setup
Change the page setup properties for the current view
**Print Preview
Display a print preview for the current view
**Print
Print the current view
**Recent Files
Displays recently opened Achieve data files
**Lock Application
Lock the application and minimize all windows (password is required to restore windows)
**Exit
Close the main window
