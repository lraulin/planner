# Achieve Time Management & Goal Setting Software Help - Standard Toolbar

_Archived from [http://www.effexis.com/achieve/online_documentation/standardtoolbar.htm](http://www.effexis.com/achieve/online_documentation/standardtoolbar.htm)_

---

The Standard Toolbar provides access to common commands.
**New Item...**
Create a new item appropriate for the current top-level view
**Save**
Save changes to the data file
**Open Selected Item(s)...**
Open any currently selected items
**Undo**
Undo the last action or command (if possible)
**Redo**
Redo the last action or command
**Cut**
Cut text from the active cell or control
**Copy**
Copy text from the active cell or control
**Paste**
Paste text into the active cell or control
**Delete**
Delete the selected row(s)
**Remove Priority Gaps
Remove gaps between priority values in the current view
**Repiroritize Unique
Reprioritize the current item so that its rank is unique
**Help**
Provide context sensitive help
**Navigate Backward**
Navigate to the previously active top-level view
**Navigate Forward**
Navigate forward to the next top-level view in the list
