# Achieve Time Management & Goal Setting Software Help - Changing Password Protection for a Data File

_Archived from [http://www.effexis.com/achieve/online_documentation/changingpasswordprotection.htm](http://www.effexis.com/achieve/online_documentation/changingpasswordprotection.htm)_

---

You can use the **File Set Password...** command in the [file menu](filemenu.md) or [standard toolbar](standardtoolbar.md) to set, change or remove the password protection for a data file. By default, Achieve data files are not password protected until you set a password. Password protected data files are also encrypted.
When you invoke the command for a non-password protected file, you will see the Set Password dialog.
To set the password, type a new password and enter an optional reminder string (that anyone trying to open the data file will be able to see) and click Set Password button. The data file will be password protected the next time it is saved.
When you invoke the command for an already password protected data file, you will see the following Set Password dialog.
You must first enter the existing password for the data file in order to be able to change or remove the password.
