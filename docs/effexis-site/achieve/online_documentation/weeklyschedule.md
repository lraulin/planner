# Achieve Time Management & Goal Setting Software Help - Weekly Schedule

_Archived from [http://www.effexis.com/achieve/online_documentation/weeklyschedule.htm](http://www.effexis.com/achieve/online_documentation/weeklyschedule.htm)_

---

The weekly schedule view is a powerful tool to help you organize your schedule and manage your time effectively.
By default, the 5 day view is displayed, but you can change the number of days displayed to one, three, five, seven, ten and twenty using the commands in the [View menu](weeklyschedulemenucommands.md) (specialized for the weekly schedule view).
You can use the weekly schedule to record appointments and events. Events are placed at the top of the day column and are considered to last the entire day (or days.) Simply select the desired time slots and type to create the new appointment or event. You can also create new appointments using the commands in the Actions menu.
The default resolution for the schedule is 15 minutes. You can change the resolution using the context menu by right-clicking on the schedule area (any non-appointment area) or on the time display area. Right-clicking on an appointment or event will provide appointment specific options.
You can toggle work week mode and the display of the month calendars using the [view menu](weeklyschedulemenucommands.md) commands.
