# Achieve Time Management & Goal Setting Software Help - Linking Appointments and Projects

_Archived from [http://www.effexis.com/achieve/online_documentation/linkingappointmentsandproje.htm](http://www.effexis.com/achieve/online_documentation/linkingappointmentsandproje.htm)_

---

You can link appointments and projects to indicate that the appointment is a Project Block for a project (see [Weekly Planning Wizard](weeklyplanningwizard.md) for details.) Appointments/events linked to a project that don't have an explicit appointment label will use the label associated with the project if it has one. This is an easy way to distinguish project blocks for different projects.
You can use the **Actions Set Project...** command to set the project for selected appointments.
To create new project blocks for an existing projects, you can simply drag them from the Projects panel on the top-right of the weekly schedule tab.
You can also change the project associated with an appointment/event through the [Appointment Information form](appointmentinformationform.md).
