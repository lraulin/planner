# Achieve Time Management & Goal Setting Software Help - Recurring Appointments

_Archived from [http://www.effexis.com/achieve/online_documentation/recurringappointments.htm](http://www.effexis.com/achieve/online_documentation/recurringappointments.htm)_

---

You can change the recurrence properties of an appointment/event through the [Appointment Information form](appointmentinformationform.md). Just click on the Recurrence button or select the **Appointment Recurrence...** command to display the recurrence dialog.
You can use the recurrence dialog to specify the recurrence pattern for the appointment/event or to remove the recurrence.
If you invoke the recurrence dialog for a recurring appointment that has any exceptions (modified instances) or deletions (deleted instances) and accept the changes, the recurrence pattern will be reset and all exceptions and deletions will be discarded. You will be presented with a dialog asking whether to save exceptions:
Select **Yes** to save all exception appointments, **No** to discard all exceptions or **Cancel** to cancel the changes. In any case, the recurrence will be reset.
