# Achieve Time Management & Goal Setting Software Help - Starting the Application

_Archived from [http://www.effexis.com/achieve/online_documentation/startingtheapplication.htm](http://www.effexis.com/achieve/online_documentation/startingtheapplication.htm)_

---

Once you have installed the software, you should have a new program folder in the Windows Start Menu under **Programs****»Effexis Achieve**. To start the application click on the Achieve item in this folder or double-click the Achieve shortcut on your desktop.
After a few seconds you should see the evaluation dialog box that indicates the software evaluation status and allows you to register the software. _Note: This dialog box will no longer appear once you register the software.

**Enter Registration Code**
Displays the registration dialog to complete software registration once you have a registration key
**Order Now
Displays the order web page online using your default browser
**Try It**
Allows you to continue evaluating the software during the trial
**Exit**
Exit from the dialog
Note: after the trial period expires, you will no longer be able to save any changes. This functionality will be restored once you register the software.
