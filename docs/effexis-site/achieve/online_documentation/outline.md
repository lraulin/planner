# Achieve Time Management & Goal Setting Software Help - Outline

_Archived from [http://www.effexis.com/achieve/online_documentation/outline.htm](http://www.effexis.com/achieve/online_documentation/outline.htm)_

---

The Outline tab displays the result areas, projects, and tasks in a single outline. See [Using Grids](usinggrids.md) for help with the grid user interface. See [Using Priorities](usingpriorities.md) for more information on how to prioritize items in the grid.
Achieve's **Projects** and **Tasks** replace the to-do list used in traditional time management systems. A **project** represents an outcome or result that you want to accomplish while **tasks** represent the action steps. Separating these two concepts will help you make better use of your time by allowing you to focus on outcomes instead of just actions and is a more effective way of keeping tack of what you need to do. See [Getting Organized Overview](gettingorganizedoverview.md) for more details.
To open the selected project row(s) and reveal the information form you can: double click on it, press _Ctrl+Enter_ or invoke the **File Open Open Selected Items...** command from the [file menu](filemenu.md) or [standard toolbar](standardtoolbar.md).
**Zooming the Outline

****The Outline grid supports zooming in (to view a selected branch of the outline) and zooming out (view more of the outline.) You can use the**View Zoom In, View Zoom Out, and View Clear Zoom** commands to zoom in, zoom out, or clear all zooming respectively.
**Outline Actions

****The outline tab supports the following commands through the Actions menu.
**View Details
View the details of the current item in the appropriate tab (Projects tab, Tasks tab, or Result Areas tab)
**Complete Item(s)**
Completes the selected item(s) (marks them as completed) and allows you to record work/expenses. See [Recording Work/Expenses](recordingworkexpenses.md) topic.
**Record Work/Expenses**
Record work/expenses for the current item
**Promote**
Promote the task into a project
**Demote**
Demote the selected project into a task
**View Email**
For projects/tasks that were imported from Outlook® emails, view the associated email in Microsoft Outlook® (see [Outlook Synchronization](outlooksynchronization.md) for details)
**Attachments...
Opens the [Project Information Form](projectinformationform.md) or [Task Information Form](taskinformationform.md) in the attachments tab so you can add/launch attachments/URLs
**Reschedule**
Reschedule all active projects/tasks based on the latest information. See [Project/Task Scheduling](projecttaskscheduling.md) for details.
**Schedule Block**
Schedule a project/task block for the selected items in the weekly schedule. The size of the project blocks is based on the "Block Size" setting in the [Project Information Form](projectinformationform.md). Press Esc key to end the block drop mode.
