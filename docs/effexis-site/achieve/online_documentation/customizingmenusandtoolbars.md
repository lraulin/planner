# Achieve Time Management & Goal Setting Software Help - Customizing Menus and Toolbars

_Archived from [http://www.effexis.com/achieve/online_documentation/customizingmenusandtoolbars.htm](http://www.effexis.com/achieve/online_documentation/customizingmenusandtoolbars.htm)_

---

Achieve supports the customization of toolbar and menu commands to adapt to the way you like to work. Toolbar and menu customization is accomplished through the Customize dialog which is displayed by right-clicking on a menu or toolbar and choosing the **Customize...** option.
**Customizing Toolbars

****The**Toolbars** tab of the Customize dialog allows you to create, delete, rename, and show/hide the various toolbars associated with the application.
**Toolbars**
List of available toolbars (check to show the toolbar, uncheck to hide the toolbar)
**New...**
Click to create a new blank toolbar (floating or docked) in which to attach commands
**Rename...**
Click to rename a user-created toolbar
**Delete...**
Click to delete a user-created toolbar
**Reset...**
Click to reset any command customizations performed on the selected toolbar or main menu
**Keyboard...**
Displays the Keyboard Customization Dialog (see [Customizing Keyboard Shortcuts](customizingthekeyboard.md))
**Close**
Close the dialog
**Customizing Toolbar and Menu Commands

****Toolbar and menu commands (contents) can be customized through the**Commands** tab of the customization dialog.
**Categories**
Filters the commands in the commands list to the commands in the specified category
**Commands**
List of commands in the chosen category (can be dragged/dropped into toolbars and menus)
**Description**
Show a brief description for the selected command
**Keyboard...**
Show the keyboard customization dialog (See [Customizing Keyboard Shortcuts](customizingthekeyboard.md))
**Close**
Close the dialog
**_To add a command to a toolbar or menu:

· Display the Customize dialog and choose the **Commands** tab
· Select the desired command from the Commands list
· Using drag & drop, drag the selected command to the desired spot in the menu or toolbar and drop it
· Hover over a popup menu to display its submenu
Press _Esc_ at any time during the drag to cancel.
**_To remove a command from a toolbar or menu:_**
· Display the Customize dialog and choose the **Commands** tab
· Select the desired command to remove from the toolbar or menu
· Hover over a popup menu to display its submenu
· Drag the command to remove off the toolbar or menu (cursor will change into an drag with x to indicate removal)
· Drop the item outside any active menu or toolbar to complete the remove
Press _Esc_ at any time during the drag to cancel.
**_To arrange/move commands in a toolbar or menu:_**
· Display the Customize dialog and choose the **Commands** tab
· Select the desired command to move from the toolbar or menu
· Drag the item to its new location and drop it
Press _Esc_ at any time during the drag to cancel.
