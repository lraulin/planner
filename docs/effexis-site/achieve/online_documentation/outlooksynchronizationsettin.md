# Achieve Time Management & Goal Setting Software Help - Outlook Synchronization Settings

_Archived from [http://www.effexis.com/achieve/online_documentation/outlooksynchronizationsettin.htm](http://www.effexis.com/achieve/online_documentation/outlooksynchronizationsettin.htm)_

---

These settings control the import/export process during Outlook® Synchronization. To change the settings, click on the **Settings...** button in the [Outlook Synchronization Dialog](outlooksynchronization.md).
**NOTE:** By default, Achieve Planner is setup to only import Outlook data without making any changes in Outlook. This is done to avoid making any unwanted changes in your Outlook data unless this is what you want.
**Import Restricted Outlook Data**
Indicates if Achieve should attempt to access restricted Outlook® data that will trigger the Outlook® security dialog during the import. Restricted data includes email addresses, message bodies, etc.
**Show Tooltips**
Indicates if tooltips should be shown for the options
**Email Options

**Import Email**
Indicates if email should be imported during synchronization. Clear to stop importing email from Outlook®
**Import Todo**
Indicates if email should be imported from the Inbox/Todo folder
**Import Waiting For**
Indicates if email should be imported from the Inbox/Waiting For folder
**Import Postponed**
Indicates if email should be imported from the Inbox/Postponed folder
**Move Completed to Processed**
Indicates if email should be moved to the Inbox/Processed folder when the associated project/task is completed
**Move Deleted to Processed**
Indicates if email should be moved to the Inbox/Processed folder when the associated project/task is deleted
**Import Sender/Receiver**
Indicates if email sender/receiver information should be imported and included in the project description
**Import Body**
Indicates if the email body should be imported and included in the project description
**Length**
Number of characters of the email body that should be imported into the project description (limiting body size will improve performance)
**Appointment Options

**Import Appointments**
Indicates if appointments/events should be imported from Outlook®
**Import Private**
Indicates if private appointments/events should be imported from Outlook®
**Import Changes**
Indicates if changes to previously imported appointments/events should be re-imported. This also includes deleting imported appointments in Achieve when they are deleted in Outlook® (appointments exported to Outlook® are not deleted in Achieve even if they are deleted in Outlook®)
**Export Appointments**
Indicates if appointments/events created in Achieve should be exported to Outlook®
**Export Private**
Indicates if private appointments/events created in Achieve should be exported to Outlook®
**Export Project Appointments**
Indicates if appointments/events linked to a project (project blocks) should be exported to Outlook®
**Date**
The date from which to start importing Outlook® appointments. Uncheck the date box to use default of two weeks prior to Today. Check the box to force the use of the specified date. (Unchecked is recommended)
**Export Deletes**
Indicates if appointments/events that were exported to Outlook® from Achieve and are subsequently deleted in Achieve should also be deleted in Outlook®
**Import Deletes**
Indicates if appointments/events that were imported from Outlook® into Achieve and were subsequently deleted in Achieve should also be deleted in Outlook®
**NOTE:** Both the **Import Appointments** and **Export Appointments** checkboxes must be checked to perform 2-way sync of appointment data.

**Task Options

**Import Tasks**
Indicates if tasks should be imported from Outlook®
**Export Tasks**
Indicates if Achieve Planner projects and tasks should be exported to Outlook
**Advanced Task Settings**
Change advanced settings for Task sync. See [advanced task sync settings topic](advancedoutlooktasksyncset.md) for details.
**NOTE:** Both the **Import Tasks** and **Export Tasks** checkboxes must be checked to perform 2-way sync of task data.

**Contact Options

**Import Contacts**
Indicates if Contacts should be imported from Outlook®
**Import Private**
Indicates if Contacts marked as private should be imported from Outlook®
**Import Changes**
Indicates if changed to Contacts that were previously imported should be synchronized
**Export Contacts**
Indicates if Contacts created in Achieve should be exported to Outlook®
**Export Private**
Indicates if private contacts in Achieve should be exported to Outlook®
**Export Deletes**
Indicates if contacts deleted in Achieve should also be deleted in Outlook®
**Reestablish Links to Existing Appointments & Contacts** - Check this box to attempt to re-establish missing links between Outlook® appointments and contacts, and existing Achieve Planner appointments and contacts based on dates & subjects for appointments, and contact name for contacts. This setting only applies during the next sync operation and resets afterward.
This is useful if you move to a different PC in which Outlook® entry ID values are different from the initial link to Achieve Planner.**

**Confirm Outlook Deletes****** \- Checking this box will provide a prompt to manually confirm any deletion of Outlook® data.
Achieve keeps track of all the items that have been imported from Outlook® to prevent them from being imported again in future synchronizations. This history is maintained even if the imported items are deleted in Achieve (and not in Outlook®.) The **Clear Deletion History** button will clear this history information for all items that have been deleted in Achieve which allows them to be reimported from Outlook®.
Note that this will only clear the history for items that have been deleted, other items will not be reimported.
The **Clear Sync History** button allows you to completely clear all the synchronization history with Outlook®. This could result in duplicated content.
