# Achieve Time Management & Goal Setting Software Help - Weekly Schedule Menu Commands

_Archived from [http://www.effexis.com/achieve/online_documentation/weeklyschedulemenucommands.htm](http://www.effexis.com/achieve/online_documentation/weeklyschedulemenucommands.htm)_

---

The Weekly Schedule view provides several additions to the View and Go menus.
The View menu provides the following additions:
**One Day**
Display a single day column
**Three Days**
Display three day columns
**Five Days**
Display five day columns
**Seven Days**
Display seven day columns
**Ten Days**
Display ten day columns
**Twenty Days**
Display twenty day columns
**Reminders Window**
Display the reminders window
**Work Week Mode**
Toggle work-week mode on/off. While in work week mode, Saturdays and Sundays are not shown
**View Month Calendars**
Toggle the display of the month calendars on the side of the schedule on/off
**Go Menu

****The Go menu provides additional commands to move to a particular date and to move to Today.
