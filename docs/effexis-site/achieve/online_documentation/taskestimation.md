# Achieve Time Management & Goal Setting Software Help - Task Estimation

_Archived from [http://www.effexis.com/achieve/online_documentation/taskestimation.htm](http://www.effexis.com/achieve/online_documentation/taskestimation.htm)_

---

The task estimation dialog can be used to enter estimates for the level of effort and cost of a task (you can also enter this information from the Active Task Estimation [tasks view](tasks.md)). You can obtain this dialog from the **Actions Estimate Effort/Cost** command.
The following values can be entered:

**Expected Effort Low**
Low estimate for the total effort required to complete the task. Represents the minimum amount of effort it could possibly take to complete the task assuming that everything went according to plan
**Expected Effort Best**
Best guess estimate for the level of effort required to complete the task
**Expected Effort High**
High estimate for the total effort required to complete the task. A reasonable upper limit on the maximum effort it could take to complete the task assuming some things go wrong or significant rework is required
**Expected Effort**
Total expected effort required to complete the task. Computed based on the Low/Best/High values
**Expected Cost Low**
Low cost estimate for the task
**Expected Cost High**
High cost estimate for the task
**Total Cost**
Total cost estimate for the task computed from the High/Low values
