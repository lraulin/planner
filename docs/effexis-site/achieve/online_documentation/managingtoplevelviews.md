# Achieve Time Management & Goal Setting Software Help - Managing Top Level Views

_Archived from [http://www.effexis.com/achieve/online_documentation/managingtoplevelviews.htm](http://www.effexis.com/achieve/online_documentation/managingtoplevelviews.htm)_

---

When multiple top-level views are being displayed simultaneously, the view tabs section of the workspace contains a tab for each view. The active view has a **bold** title.
The view tabs can be used to activate a view or to close the active view through the close button (x). The scroll arrows bring hidden tabs into view.
The order of the view tabs can be changed by dragging tabs to their desired location.
The view tabs are also used to create horizontal and vertical tab groups for the workspace (similar to Visual Studio) via the context menu. Simply right click on a view tab to display the context menu and select the desired command.
Once tab groups have been created, views can be moved from one group to another by dragging the tab or by invoking the appropriate command through the context menu.
