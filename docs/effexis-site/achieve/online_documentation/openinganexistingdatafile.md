# Achieve Time Management & Goal Setting Software Help - Opening an Existing Data File

_Archived from [http://www.effexis.com/achieve/online_documentation/openinganexistingdatafile.htm](http://www.effexis.com/achieve/online_documentation/openinganexistingdatafile.htm)_

---

**_To open an existing data file:

· Invoke the **File Open Open File...** command from the [file menu](filemenu.md)
· Browse and select the desired data file
If the data file has been opened recently, it may be present in the recent files list (**File Recent Files**) of the [file menu](filemenu.md). To open simply select the desired file from this list.
