# Installing the Latest Achieve Planner Version

This page walks you through the process of installing the latest Achieve Planner version.
**IMPORTANT:** Use the Help -> About menu item in Achieve Planner to find out what version of the software you are currently using.
If you already have version 2.0 or later, please [click here](#20Users) for instructions on how to install the latest version.
**Section 1 - For Achieve Planner 1.x Users Only**
The latest 2.x release does NOT work with version 1.x registration codes.
If you currently have version 1.9 or earlier and you want to upgrade to the new 2.0 version, please [ click here](new-version-upgrade.md).
If you want to download the latest 1.9 release _without_ upgrading to the new 2.0 version, please [click here](AchievePlanner19Download.md).
**Section 2 - For Current Achieve Planner 2.x Users**
If you currently have version 2.0 or later, follow the steps below to install the latest version.
**Installing Latest 2.x Release (For Existing 2.x Users)**
Here are the steps for installing the latest Achieve Planner 2.x release...

1.  **Make a backup copy of your data file (.ach)** \- **I highly recommend that you make a backup of your data file in case of problems.** It is always a good idea to make a backup of your data file before installing a new version.
    The format of the data file may change in future versions of Achieve Planner, so you may not be able to open files created in future versions of AP with older versions.
    If you haven't done it already, you may also want to enable auto-backup of your data file. Here's how:
    1.1) Tools -> Options menu item
    1.2) Save tab
    1.3) Make sure the 'Enable Auto-Backup' box is checked
    1.4) Leave the path blank (default backup directory) or set it to a specific directory where you want your backups stored
2.  [ Click here to go to the Achieve Planner download area ](download.md)
3.  Download the latest Achieve Planner installer (Achieve2Setup.exe)
4.  Run the installer - This should automatically install the latest version
5.  Launch Achieve Planner
    NOTE: Updates to the latest Achieve Planner version are free if they are in the same Major Release number as your current version.
    For example, if you purchased version 1.6, you can get free updates to all 1.x versions. You only have to pay an upgrade fee when moving to a new major release version like 2.x
    Learn more about the new version [upgrade policy here](upgrades.md).
    **Installing Older Achieve Planner 1.9 Releases**
    Achieve Planner is currently in the 2.x release series. If you are an existing customer and don't want to upgrade to the 2.x series, you can [download and install the last 1.9 release here](AchievePlanner19Download.md).
